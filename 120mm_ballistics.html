模型与文献

MODEL ASSUMPTIONS / VALIDATION / REFERENCES

1 · 弹型预设

  • A · 120mm 迫弹（默认）：尾翼稳定、全程不旋转。质量/惯量取自 McCoy 表 9.5（M934/M930/M929 平均），气动系数取自 McCoy 附录 C（BRL 跨音速靶道自由飞试验）；v0=318 m/s、45° 对应 6-DOF 射程 7315 m。
  • B · 120mm 旋转稳定杀爆弹代表弹：线膛炮发射，自转由缠距换算（默认 1:18）；气动系数按 McCoy 附录 B 的 105mm HE M1 同类弹换算（估算值），内核以 105mm M1 参数完成验证。
  • 破片质量分布/初速由 Gurney + Mott 模型给出；装药与壳体质量为工程估算（公开数据缺失），页面已标注。

2 · 六自由度刚体外弹道

  • 状态量：位置、速度、四元数姿态、弹体系角速度（15 维，含科氏力侧偏累积量）；RK4 积分，步长按自转自适应（≤0.5 ms）。
  • 弹体动力学：欧拉方程 I·ω̇ + ω×(Iω) = M；四元数归一化避免欧拉奇异。
  • 气动角按相对风速计算；风场通过相对速度进入气动力与力矩。
  • 事件：下降段穿越空炸高度 / 触地，线性插值得到起爆点状态；给出 Sg、偏流、风偏、科氏偏移等诊断量。

3 · 气动模型（BRL 命名法）

CD = CD0 + CDδ2·sin²αt
CN = (CNα0 + CNα2·sin²αt)·sinαt
CMα = CMα0 + CMα2·sin²αt（正 = 翻转，需自转稳定；负 = 静稳定）
M阻尼 = q·S·d²/V·[(CMq+CMα̇)0 + (…)2·sin²αt]·ω
MMagnus = q·S·d·(p·d/V)·CMpα（仅旋转弹）

旋转弹陀螺稳定因子 Sg = (Ix·p)² / (4·Iy·q·S·d·CMα)，Sg > 1 为稳定必要条件；尾翼弹给出静稳定裕度 −CMα/CNα（口径）。

4 · 环境模型

  • ISA 标准大气分层公式（0–11 / 11–20 / 20–32 km），支持海平面气温偏移（ISO 2533 / GB 1920）。
  • 风场：横风/纵风 + 幂律高度剖面 w(h)=w10(h/10)1/7。
  • 科氏力：a = −2Ω×v，按纬度与射向计算（40°N、7 km 射程量级 10–20 m）。
  • 重力随高度衰减 g(h)=g₀(R/(R+h))²；平面地球假设。

5 · 动爆破片

  • 质量分布：Mott 分布 N(>m)=N₀e−√(m/μ)，平均质量 = 2μ，质量守恒归一。破片数为 Monte-Carlo 统计样本数（默认 800，可调 200–1600），由 Mott 分布描述总体，不等同于该型号全部物理破片数。
  • 初速：Gurney 公式 vG=√(2E·β/(1+β/2))，β=C/M；端部折减 + 分区速度因子。
  • 动爆叠加：弹丸速度矢量 + 自转切向速度 ω×r；飞散角按弹头/圆柱/弹底三区截短正态。
  • 存速：变密度大气 + 马赫相关 Cd + 体积2/3 迎风面积 + 风场相对速度（RK4，步长 5 ms；落地速度线性插值）。
  • 统计口径：R50/R90 为 50%/90% 已落地破片的水平落点半径（相对爆点地面投影），不是杀伤半径；有效破片按落地动能 > 78 J（人员致伤阈值量级，中文出处：李昆等 2023；80 J 另见 Rettinger 2017）统计；随机抽样种子固定可复现。

8 · 模型假设与局限

  • 刚体、轴对称、质量/惯量恒定；气动模型适用于小攻角（一般 αt<10°），更大攻角（高射角弹道顶点）为定性参考。
  • 120mm 迫弹气动数据止于 Ma 0.95（实弹 v0≤318 m/s）；提高初速属外推。旋转弹气动系数由 105mm M1 同类换算，非 120mm 实测。
  • 未计气动不对称、动不平衡、引信延时与炸高散布；空炸高度为标称值。
  • 破片为自然破片统计模型（装药/壳体/飞散角为工程设定），未计壳体结构强度细节；杀伤仅用动能阈值，未计目标易损性。
  • 平面地球 + 常值重力 + 可选科氏力；不含地球曲率、离心力与地形。
  • 本模型用于教学演示与趋势分析，不用于射表编制或实弹射击诸元计算。
