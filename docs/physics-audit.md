## 0. 结论摘要

基线共发现 **34 条问题：P0=5、P1=11、P2=12、P3=6**。核心结论：

1. **6DOF 数值积分本身没问题，但仅对“spin=18 rad/s 的假工况”成立**：该工况 dt=1ms 已收敛到 1e-4 m 量级；一旦换成真实线膛自转（~1000–1300 rad/s），dt=1ms 完全不收敛（同样参数仅改 dt，飞行时间散布 30.6 s、射程散布 4021 m，4 ms 步长在 0.02 s 内数值爆炸）。
2. **自转 18 rad/s 与任何真实 120mm 弹不匹配**：滑膛（120mm 坦克炮 M256、120mm 迫击炮 M120）应为 0；线膛 450 m/s 下 1:18/1:20/1:25 缠度分别为 1309/1178/942 rad/s。18 rad/s 相当于 1:1309 的缠度，只是“让画面有转速”的伪参数。
3. **模型气动参数在真实自转下自相矛盾**：默认静稳定裕度 0.64 cal、Magnus 力矩系数 1.30 时，对 `deriv` 的数值线性化在 spin≥600 rad/s 即出现正实部（spin=1178 时 Reλ≈+1.53 /s）；非线性仿真在真实自转下 20 s 内攻角放大到 76–78°（翻滚）。关闭 Magnus 后降为 ~8.5°，符号翻转后 ~3.5° ⇒ 失稳主因是 Magnus 量级/符号，其次才是 Sg 余量。真实弹不会翻滚 ⇒ 气动数据/静稳定裕度/自转三者必须在重写时一起重标定。
4. **大气模型只覆盖对流层**：11 km 以上仍按 -6.5 K/km 外推到 20 km，20 km 处 T 低 27%、声速低 14.6%、压力低 21%；h>20 km 直接冻结为 20 km 密度。基线（Hmax 2737 m）与现有 UI 极值（Hmax 5889 m）不触发，但任何更高初速/射角都会进入错误区。
5. **破片模型“看着对、统计口径弱”**：质量守恒精确（Σ=10.5 kg）、Mott 采样器 KS p=0.62 通过；但质量分布被截断/重归一化扭曲（8 枚 227 g 等质量大破片）；R90 无定义（等权 435 m / 质量加权 819 m / 能量加权 39 m）；r90 种子间 CV 5.7%，r50 CV 28%；破片 RK2 dt=0.01 s 使平均落地速度偏低 5.1%、总动能偏低 7.6%。
6. **无风侧偏 2.9 m 的来源已定位**：自转×重力转弯小攻角升力不对称 2.18 m + 硬编码初始 wz=1.25 rad/s 贡献 0.72 m；**与风无关**（`cfg.windZ` 只出现在注释里，从未实现）。
7. **性能**：原生 Node 基线 `simulate(420 破片)` 约 12–15 ms（弹道 8–9 ms、破片 4–6 ms），浏览器无错误、60 FPS（vsync 上限）、DOM 完整；单文件包与源文件已不同步（升级期间需重跑 `node _build.js`）。

## 1. P0 问题（物理错误/不真实）

### P0-1 自转默认值 18 rad/s 对真实 120mm 弹不成立【C/C3】

- 现象：`simulate()` 默认 `spin=18`，HUD 显示“转速 18 rad/s”，但 120mm 坦克炮 M256/Rh-120 与 120mm 迫击炮 M120 均为滑膛（自转≈0）；线膛弹按 `ω=2πv/(n·d)`，v=450 m/s、d=0.12 m 时 1:18→1309、1:20→1178、1:25→942 rad/s。
- 证据：基线 code 第 243/257 行 `spin=18`、`y[10]=spin`；`1:18` 缠度对应 1309 rad/s，是 18 的 73 倍；Magnus 力矩因此只有真实值的 1.4%（C7：1.1 N·m vs 68.7 N·m @α=1 rad）。
- 影响量级：HUD 转速、滚转阻尼、陀螺耦合、Magnus 力矩全部失真；6DOF 退化为“准 3DOF + 装饰性旋转”。
- 建议：从缠度/初速换算自转（如 1:18 → 1309 rad/s），并在 UI 标明缠度；或若定位滑膛弹，spin=0 并删除 Magnus 项。
- 重写后状态（待复验）：Lead 已改为默认 1:18、450 m/s → 1309 rad/s ✅

### P0-2 自转↔气动参数不自洽：Sg≪1 与“旋转稳定”矛盾【C/C2】

- 现象：基线静稳定裕度 (xcp−xcg)/d=0.64 cal（Ma=1.32），X、Y 惯量 Ix=0.026、Iy=0.58；spi=18 时陀螺稳定因子 Sg≈3.1e-4（≪1，即毫无陀螺稳定）；而真实自转 1178/1309 rad/s 时 Sg 仅 1.32/1.64（勉强过 1，设计通常要求 ≥1.2–1.5 并留裕度）。
- 证据：C2 表；Sg=Ix²p²/(4·Iy·q·S·d·|C_Mα|)（文献调研确认 McCoy 形式）；要 Sg≥1 需 p≥1024 rad/s（1:23），要 Sg≥1.5 需 p≥1254 rad/s（1:18.8）。基线模型实际靠“俯仰阻尼 + 无陀螺”维持小攻角，不是旋转稳定弹的真实机理。
- 影响量级：真实自转 + 当前 Magnus 系数会直接翻滚（P0-3/P0-4）。
- 建议：重写时按真实弹重标 Ix/Iy、静稳定裕度与自转，使 Sg≥1.2–1.5 且 α 有界；并在 UI/诊断里显示 Sg。
- 重写后状态（待复验）：Lead 已改用 McCoy 气动表、CMα>0（静不稳定靠自转稳定）、Ix=0.0266/Iy=0.2646、真实自转，Sg 诊断已加入；需用 McCoy 算例核对（见最终复验）。

### P0-3 模型方程在真实自转下线性不稳定【C/C4】

- 现象：把 `deriv` 在配平点做数值有限差分线性化（状态 [α,β,wy,wz]），Magnus 开启时 spin≥600 rad/s 出现正实部：spin=600 → Reλ=+0.72/s；1178 → +1.53/s（时间常数 0.65 s）；3000 → +2.16/s。非线性仿真：spin=1178 时 20 s 内 max|α|≈78°（翻滚）。
- 证据：C4 表（数值线性化，非解析假设）；C5 baseline 行 78.4°；A2 中 spin=1200 的轨迹对 dt 高度敏感（混沌），佐证模型处于不稳定区。
- 影响量级：任何真实自转下都无法得到有意义的 6DOF 弹道；UI 会表现为弹丸乱飞/大攻角。
- 建议：以“Sg>1.2–1.5 且所有线性模态 Reλ<0”为验收条件重标气动系数；升级后必须复跑本项目 C4 数值线性化回归。
- 重写后状态（待复验）：已换 BRL/McCoy 系数与 CMα 符号，需复验 Reλ<0。

### P0-4 失稳主因：Magnus 力矩系数 1.30 过大/符号可疑【C/C5】

- 现象：保持其它参数不变，把 C_mag 从 1.30 改为 0：线性 Reλ 由 +1.53/s 变 -0.16/s，非线性 max|α| 由 78.4° 降为 8.4°；改成 -1.30（符号翻转）→ 3.5°；0.10 → 8.9°；0.30 → 13.0°。说明 1.30 的量级本身使真实自转工况失稳，且符号与“稳定方向”相反。
- 证据：C5 表；Magnus 力矩 68.7 N·m（22% 静力矩）@p=1178；文献调研无法给出可核实 C_npα 数值（需 CFD/风洞标定），但“1.30 + 失稳 + 翻转更稳”三者组合足以判定该系数不可信。
- 影响量级：真实自转下攻角 78°→翻滚；即使修好自转，Magnus 系数不标定仍会翻滚。
- 建议：采用 McCoy/BRL 的 CMp（Magnus 力矩）实测表（Lead 重写已做），并做符号/量级回归：真实自转、小扰动下 α 应保持 ≲2–3°。
- 重写后状态（待复验）：已引入 CMp/CNp，需复验符号与 α 有界。

### P0-5 dt=1ms 对真实自转（~1200 rad/s）完全不收敛【A/A2】

- 现象：真实自转下每步相位 1200×1e-3=1.2 rad，RK4 相位误差 O(θ⁵) 累积。同一 spin=1200 配置仅改 dt（2/1/0.5/0.25/0.1 ms，参考 5e-5）：飞行时间 42.5/58.1/68.3/73.05/73.12 s，射程 8502/11669/12411/12514/12523 m —— 飞行时间散布 **30.6 s**、射程散布 **4021 m**；dt=4 ms 在 0.02 s 内数值爆炸（NaN）。
- 证据：A2 表；A3（关闭 Magnus 后的稳定配置）dt=1ms 姿态误差仍为 4.1°、位置误差 67 m，需 dt≤2.5e-4 才降到 0.26 m/0.42°；A4 显示 spin=1200,dt=1ms 时归一化前四元数模长误差 3.1e-4（dt=1e-4 时 3.2e-10）。
- 影响量级：不改 dt 就得不出可用的真实自转 6DOF 结果。
- 建议：dt 随自转自适应（例如 dt≤0.3/|spin|，1200 rad/s 时 ≤0.25 ms），并保留步长收敛回归（0.5/0.25/0.125 ms 三档）。
- 重写后状态（待复验）：Lead 已实现自适应 dt≈0.34/|spin|（默认约 0.26 ms）；必须用 0.5/0.25/0.125 ms 复验收敛性。

## 3. P2/P3 问题（工程/统计/文档）

- **A4 四元数归一化**：每步归一化把模长误差压到 O(1e-14)（spin=18,dt=1ms）~O(1e-4)（spin=1200,dt=1ms），模长不会发散；但归一化不修正姿态相位误差（见 A3）。→ 无需改代码，随 dt 一起复验。
- **B4 20 km 截断**：h>20 km 冻结密度 0.0953 kg/m³（非真空）；当前 UI 不可达。→ 重写分层大气后确认无此问题。
- **C7 滚转阻尼 C_lp=−0.06**：基线 46.6 s 内自转 18→6.3 rad/s（−65%）；若真实 C_lp=−0.01/−0.02，则只衰减 16%/29%。数值待对标。→ 重写用 BRL Clp 表，需核对衰减量级。
- **C8a windZ 未实现**：源码中 windZ 只出现在文档字符串（1 次），deriv/simulate 无风场项。→ 重写已加横/纵风+幂律剖面，复验方向（顺风增速、逆风减速、横风侧偏方向）。
- **C8b 攻角 guard 不连续**：`if (ub > 0.2*V)`（|α|>78.5°）时 α、β 强制置 0，气动力/力矩突然消失；翻滚工况每 1000 个采样触发 1–7 次。→ 复验重写是否保留该 guard。
- **D1 破片质量分布被扭曲**：质量守恒靠事后归一化强制（Σ=10.5 kg 精确），但分区质量因子 + [0.05,8]×均值截断产生 8 枚 227 g 等质量大破片（120mm 薄壁杀爆弹偏大）。→ 建议按分区定义 Mott μ 或标注“示意模型”。
- **D3 破片初速能量不闭合**：Σ½m·v_rel²=6261 kJ 仅为 Gurney 理想值 8261 kJ 的 75.8%（端部/质量修正“吃掉”能量）；需在模型说明中明确。
- **D5 78J 统计口径弱**：227/420 枚 >78 J，仅给“枚数”，不含杀伤面积/概率；文献可核实的是 80 J 判据（Rettinger 2017）；`effectiveCount(landV>100)` 是死代码。→ UI 标注“78J（≈80J 判据）”。
- **D6 随机不可复现**：全局 `Math.random()` 无种子入口；同参数两次 r90 可差 4 m。→ 建议 simulate 接受 seed。
- **E5 参数不对应真实型号**：450 m/s、15.5 kg 与 M120（318 m/s、13.65 kg、滑膛）及 120mm 坦克炮（滑膛）都不符；建议 UI 标注“典型参数，非特定型号”。
- **F1/F3 性能**：基线原生 12–15 ms（弹道 8–9 ms + 破片 4–6 ms，破片占 35–41%）；dt 减半耗时约 ×1.6–1.9；建议复用 atmosphere()/aeroAt() 返回值、预计算破片 Aref、减少对象分配（预计 10–20%）。
- **文档一致性**：simulate 注释 maxTime 默认 120，代码 140；cfg.windZ 文档存在但未实现（C8c）。

## 5. 给内核升级的最小验收清单（建议）

1. **自转**：默认由缠度换算（1:18 → 1309 rad/s@450 m/s）；复验 HUD 转速随初速变化。
2. **dt**：自适应步长下做 0.5/0.25/0.125 ms 收敛性（飞行时间差 <0.1%、射程差 <0.5%、α 差 <0.1°）。
3. **气动**：复跑 C4 数值线性化，所有工作自转下 Reλ<0；非线性 α_max≲2–3°；Sg 显示且 ≥1.2–1.5。
4. **大气**：ISA 0/5/10/20/32 km 与标准值对比（ρ/a/T 误差 <0.5%），高升弧不再冻结。
5. **风/科氏**：顺风射程↑、逆风射程↓、横风侧偏方向正确；北半球向右（或按科氏项符号）且量级 ~2Ωv·t² 量级。
6. **破片**：Σm=壳体质量（1e-6 相对）；R90 定义写清并复现（种子）；破片 dt≤0.0025 或 RK4；78J 标注“≈80J 判据”。
7. **构建**：`node _build.js` 后校验 120mm_ballistics.html 内联 hash 与源文件一致 + 浏览器冒烟 0 错误。
